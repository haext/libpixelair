# libpixelair

Python library for controlling pixelair (fluora) devices over a local network.

# Creation

```bash
py -m venv .venv
.\.venv\Scripts\activate
python -m pip install poetry
py -m poetry new libpixelaircoap
```

# Development

```bash
.\.venv\Scripts\activate
py -m pip install .
```
